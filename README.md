# Рычаг — биомеханика упражнений

Сайт: https://fallange1.github.io/rychag/

Интерактивные схемы: меняешь положение тела — видишь, как меняются рычаги и какая мышца берёт нагрузку.
Упражнения: жим ногами, присед, ягодичный мост, жим лёжа, тяга в наклоне, сгибания на бицепс,
румынская тяга, махи в стороны, тяга верхнего блока.

Тёмная тема по умолчанию, переключатель — в шапке (`assets/js/theme.js`, выбор запоминается).

## Запуск

Сборка не нужна. Из папки проекта:

```bash
python tools/serve.py
```

Открыть http://localhost:5173

## Публикация

Сайт живёт на GitHub Pages и обновляется сам: достаточно отправить изменения в ветку `main`
(`git push`), через минуту новая версия будет на сайте.

## Устройство

- `index.html` — главная, карточки с живыми мини-анимациями.
- `exercises/*.html` — страницы упражнений. Эталон — `leg-press.html`, остальные собираются из него:
  `python tools/build_pages.py` (тексты страниц лежат в этом же скрипте).
- `assets/js/bio.js` — математика: векторы, кинематика двух звеньев, моменты в суставах.
- `assets/js/scene.js` — общий движок сцены: SVG, силуэт тела, мышцы со свечением,
  перетаскиваемые ручки, повторения, пометки «ручкой» (на телефоне — номера на картинке
  и список под ней). У модели можно задать `mobileViewBox` — кадр крупнее для телефона.
- `assets/js/exercise-page.js` — общая страница: панель мышц, подсказки, ползунок, пресеты.
- `assets/js/<упражнение>.js` — модель упражнения (`model`) и тексты панели (`page`).
- `assets/css/style.css` — стили, светлая и тёмная тема.

## Как добавить упражнение

1. Скопировать любой `assets/js/<упражнение>.js` и описать модель: `initial`, `clamp`, `solve`,
   `draw`, `handles`, `notes`, `animate`, а в `page` — мышцы, ползунок, пресеты и `read()`.
2. Добавить тексты страницы в `PAGES` в `tools/build_pages.py` и запустить его.
3. Добавить карточку и `<script>` на главную.

## Физика

Модели плоские, кости жёсткие, движение медленное. Работа мышцы = момент в суставе =
сила × плечо (перпендикуляр от сустава до линии силы). В свободных весах сила тяжести
вертикальна, и учитывается равновесие: центр масс над серединой стопы.
